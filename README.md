# best-game-01 entry: Glowkeeper

Glowkeeper is an original twin-stick arena-defense game: a lantern spirit guards five glowblooms in a moonlit garden against 10 waves of gloom creatures, ending in a three-phase boss fight. It runs offline in a desktop browser from its own files, with no dependencies and no network requests — an entry for the [best-game-01](https://make.fun/bounty/best-game-01) competition on [make.fun](https://make.fun).

Controls: WASD/arrows to move, mouse to aim, hold click or Space to shoot, Shift/right-click to dash, P pause, M mute.
